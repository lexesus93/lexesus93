## Сейчас в фокусе

### Сайты-визитки и лендинги для специалистов

Создаю сайты для консультантов, психологов, врачей, преподавателей и других специалистов, чья работа требует содержательного представления.

Такой проект включает:

- изучение профессионального опыта и материалов;
- стартовый пакет вопросов и интервью;
- определение аудитории, услуг и клиентских сценариев;
- структуру и тексты страницы;
- индивидуальное визуальное решение;
- адаптивную вёрстку;
- форму обращения и интеграцию с мессенджерами;
- при необходимости — дополнительную языковую версию;
- публикацию и техническую документацию.

Если содержание уже подготовлено, работа начинается со структуры и разработки. Если исходный материал пока состоит из биографии, документов и отдельных мыслей, сначала проводится распаковка практики.

### Текущий фриланс-кейс — сайт практики «Присутствие»

Персональный сайт для психолога, сейчас находится в работе.

В проект вошли:

- исследование практики и двух направлений работы;
- маршрут интервью и итоговая структура содержания;
- спокойная визуальная система;
- русская и английская версии;
- адаптивная HTML/CSS/JavaScript-реализация;
- форма первого обращения;
- переход в Telegram или Max;
- серверная обработка заявки через Yandex Cloud Functions;
- email-доставка и безопасное уведомление владельца;
- документы о конфиденциальности, согласии и условиях работы.
