За плечами — более двадцати лет в разработке, архитектуре, Data & AI, технологическом консалтинге и управлении внедрениями. Работал в IBM, SAP, CNET и Астра. Сегодня этот опыт соединяется с непосредственной разработкой собственных и заказных проектов.

## От идеи к продукту

Не каждая задача приходит с готовым техническим заданием. Иногда исходным материалом становится профессиональный опыт, набор документов, существующий процесс или идея будущего сервиса.

В таких проектах я сначала исследую предметную область: провожу интервью, изучаю материалы, выделяю аудиторию и сценарии, формирую структуру решения и критерии готовности. После этого проект превращается в архитектурную записку, прототип, сайт или работающий сервис.

Так появился, например, формат создания сайтов для специалистов: профессиональный опыт последовательно превращается в позиционирование, структуру содержания, тексты, визуальную систему и готовый web-продукт.

## Избранные проекты

### Corporate Knowledge Assistant

Корпоративная база знаний и AI-помощник для технической поддержки и пресейла.

Система загружает и индексирует документы, определяет тип запроса и направляет его в нужный сценарий: поиск по базе, работу с вложениями, OCR или интеграцию с трекером.

`Python · FastAPI · Celery · React · PostgreSQL · Redis · Qdrant · Docker`

### [Safe Dialog](https://github.com/lexesus93/safe_dialog)

Контур для безопасной работы с облачными языковыми моделями. Чувствительные сущности определяются и маскируются локально, после чего обработанный текст отправляется модели. В полученном ответе данные восстанавливаются.

`FastAPI · React · TypeScript · Ollama · OpenRouter · Docker`

### [Telegram Knowledge Assistant](https://github.com/lexesus93/tg_magician)

История Telegram-группы превращается в базу знаний. Сообщения загружаются в PostgreSQL, индексируются в Qdrant и используются для ответов со ссылками на исходный контекст.

`Python · FastAPI · Telethon · PostgreSQL · Qdrant · vLLM`

### Meridian Lab

Исследовательская среда для работы с рыночными данными: внешние API, хранение и кэширование, аналитические интерфейсы, проверка гипотез и ML-эксперименты на GPU.

`Go · gRPC · PostgreSQL · React · Docker · Python/ML`

### [Okno Vozm](https://github.com/lexesus93/okno_vozm)

Персональная система карьерной аналитики. Объединяет несколько версий резюме, сопоставление опыта с вакансиями, подготовку материалов и управление откликами.

`Python · FastAPI · React · Electron · SQLite · Docker`

### [Slides Wanted](https://github.com/lexesus93/slides_wanted)

Инструмент, который превращает исходную идею в структуру презентации, тексты, предварительный просмотр слайдов и готовый PPTX.

`React · Express · TypeScript · OpenAI-compatible API · pptxgenjs`

### Contact Intake Bot

Единая приёмная для Telegram и Max. Бот проводит посетителя по короткому сценарию, собирает контекст обращения и передаёт структурированную заявку владельцу.

`Node.js · Fastify · Grammy · Max Bot API · Nodemailer`

### ChatWithMe

Self-hosted интерфейс для общения с несколькими языковыми моделями и подключения собственных источников знаний.

`React · FastAPI · SQLite · Docker Compose`

### Блиц ПДД

Desktop-приложение, которое распознаёт экзаменационный вопрос на снимке экрана и находит ответ с пояснением в локальной базе билетов.

`Electron · React · Tesseract · Python`
